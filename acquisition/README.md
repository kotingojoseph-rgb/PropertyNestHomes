# PropertyNestHomes
## PropTech Marketplace — Acquisition Opportunity

### Overview

PropertyNestHomes is a full-stack real-estate marketplace platform designed to connect property owners, buyers, sellers and real-estate professionals.

The platform includes a modern web application, Node.js backend, PostgreSQL database, administrative functionality, property verification, messaging, realtime communication, payment infrastructure and an Android/Capacitor application project.
