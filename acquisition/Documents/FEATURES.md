# PropertyNestHomes — Feature & Asset Overview

## What the Buyer Is Acquiring

PropertyNestHomes is a ready-built PropTech marketplace platform that can be continued under the existing brand or rebranded by a new owner.

The acquisition includes the application source code, backend, database structure, Android project, deployment configuration and supporting technical assets.

- Bedrooms
