# PropertyNestHomes — Buyer Handover Plan

## 1. Acquisition

The buyer will acquire the agreed PropertyNestHomes software assets and related intellectual property included in the final purchase agreement.

The exact assets transferred will be documented in the executed acquisition agreement.

---

## 2. Source Code

The buyer will receive the PropertyNestHomes frontend and backend source code.

The source includes:

- React/Vite frontend
- Node.js/Express backend
- Socket.IO realtime functionality
- Database migrations
- Android/Capacitor project
- Application assets

---

## 3. Database

The buyer will receive the database schema and migration files required to recreate the application database.

A production database transfer or export should only occur after the acquisition terms have been agreed and the appropriate security procedures have been established.

---

## 4. Deployment

The application currently uses:

- Render
- Neon PostgreSQL
- Cloudinary

Deployment credentials should be transferred securely after completion of the relevant transaction stage.

---

## 5. Domain and Brand

If included in the final agreement, the buyer may receive the PropertyNestHomes domain, brand assets and related digital assets.

Ownership and transfer of these assets should be explicitly stated in the purchase agreement.

---

## 6. Credentials

Passwords, API keys, database credentials and private keys are NOT included in the public acquisition package.

Credentials should be transferred securely and only after the relevant transaction conditions have been satisfied.

---

## 7. Technical Handover

The seller can provide reasonable technical handover assistance covering:

- Project structure
- Frontend deployment
- Backend deployment
- Database configuration
- Environment variables
- Cloudinary configuration
- Payment configuration
- Socket.IO configuration
- Android build configuration

The exact duration and scope of support should be agreed in the acquisition agreement.

---

## 8. Buyer Responsibilities

After transfer, the buyer will be responsible for:

- Hosting costs
- Database costs
- Cloud storage costs
- Email/SMS provider costs
- Payment provider accounts
- App-store accounts
- Domain renewal
- Advertising and marketing
- Future development

---

## 9. Verification

The buyer should perform independent technical and commercial due diligence before completing the acquisition.

The buyer may verify:

- Source code
- Production deployment
- Database structure
- Application functionality
- Third-party integrations
- Existing users
- Existing properties
- Payment records
- Hosting configuration

---

## 10. Current Business Stage

PropertyNestHomes is an early-stage technology product.

The current platform has limited user activity and should not be represented as a mature or highly profitable business.

The primary acquisition value is the existing software, architecture, marketplace functionality, development work and opportunity for future commercialization.
